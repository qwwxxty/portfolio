# Artur Kulik — portfolio (immersive)

Одностраничный сайт-портфолио монтажёра рилсов и Shorts. Весь сайт — один монтаж на таймлайне: прокрутка работает как плейхед, внизу закреплён настоящий таймлайн монтажки с тайм-кодом SMPTE `00:00:00:00 → 00:06:44:00`. Шесть сцен: 01 Slate, 02 Selects, 03 Two looks, 04 Layers, 05 Rate card, 06 Export. Концепция, палитра, шрифты и контраст — в [DESIGN.md](DESIGN.md).

Без сборщиков и npm: работает на GitHub Pages и Netlify как есть.

```
index.html      весь текст сайта, статичная версия-постеры (работает без JS)
styles.css      палитра, шкала шрифтов, статичный и иммерсивный режимы
script.js       таймлайн-навигация, плеер, слайдер сравнения + 3D-слой (three.js, GSAP)
encode.sh       кодирование видео для слотов (ffmpeg)
assets/media/   рилсы, превью, ролики сравнения, постеры (без изменений)
assets/img/     заглушка портрета
assets/videos/  слоты под новые видео сцен (пока пусто, см. VIDEOS.md)
DESIGN.md  PHOTOS.md  VIDEOS.md
```

## Как это работает

- **Статичная версия** — это обычный HTML: те же шесть сцен как постеры с текстом, плеер, слайдер сравнения, навигация. Её видят все без JS, браузеры без WebGL2, посетители с `prefers-reduced-motion`, а также все, если CDN не ответил.
- **Иммерсивный режим** включается, только когда есть WebGL2 и с CDN загрузились three.js 0.170.0 и GSAP 3.12.5 (точные версии в import map, динамический `import()` в `try/catch`, таймаут 12 с, после него — статичная версия). Тогда к `<html>` добавляется класс `is-immersive`.
- Весь важный текст — HTML поверх сцены (его видят Google и экранные дикторы). Canvas помечен `aria-hidden`.
- Главное действие «Book an edit» (письмо на почту) всегда в шапке; таймлайн внизу ведёт к любой сцене (клик по клипу или перетаскивание плейхеда).
- Экран загрузки показывает реальный прогресс (шрифты → three.js → GSAP → сборка сцен → компиляция шейдеров); «Skip intro» сразу открывает контент.
- Скорость: на телефоне 9 000 частиц, devicePixelRatio ≤ 1.5, без bloom; на десктопе 24 000 частиц и bloom. При среднем FPS ниже 48 качество снижается ступенями (bloom → DPR → половина частиц). Рендер на паузе, когда вкладка скрыта или открыт плеер. Видео грузятся лениво, когда их сцена рядом.
- Для проверки можно зафиксировать качество параметром `?quality=0…3` (3 — максимум, адаптация отключается).

## Как опубликовать на GitHub Pages

Сейчас Pages публикует ветку `main` (старая версия сайта на https://qwwxxty.github.io/portfolio/). Новая версия лежит в ветке **`claude/hopeful-newton-4j3s9p`** и на опубликованный сайт не влияет, пока вы сами этого не решите.

**Вариант А — заменить сайт (рекомендую):**
1. На GitHub откройте Pull request из `claude/hopeful-newton-4j3s9p` в `main` и смёржите его.
2. Pages сам пересоберёт сайт из `main` за 1–2 минуты. Настройки Pages менять не нужно (Settings → Pages → Source: Deploy from a branch, `main`, `/ (root)`).

**Вариант Б — сначала посмотреть вживую:** Settings → Pages → Branch → выберите `claude/hopeful-newton-4j3s9p`, папка `/ (root)` → Save. Вернуть старую версию — снова выбрать `main`.

Все пути в коде относительные, поэтому сайт работает и в подпапке `/portfolio/`. Файл `.nojekyll` на месте.

Netlify: «Add new site → Import from Git», ветка `main` (или эта ветка), build command пустой, publish directory `/`.

## Как добавить рилс

1. Положите файлы под одним именем: `assets/media/reels/<имя>.mp4` (720×1280, со звуком), `previews/<имя>.mp4` (6 с, без звука), `posters/<имя>.jpg` (720×1280).
2. В `index.html` скопируйте блок `<li class="reel" …>` в сцене 02 и поменяйте имя, название, описание, теги, длительность и номер (`01 / 07`). Карточка в 3D-бобине появится сама.
3. Если рилсов станет больше 7, увеличьте высоту сцены `.is-immersive .scene--selects` в `styles.css` (сейчас `620svh`).

Видео для фоновых слотов сцен — в [VIDEOS.md](VIDEOS.md), фото — в [PHOTOS.md](PHOTOS.md).

## Припущення

1. **Рилсы.** В анкете сказано, что рилсы будут в `assets/videos/` позже, но там же — взять ссылки на рилсы из текущего сайта. Поэтому все 9 существующих рилсов (`assets/media/`) показаны сразу, а `assets/videos/` отведена под три новых слота сцен: фон 01 (`hero`), видео со скроллом в 04 (`scrub`), фон 06 (`export`). Статус слота — простой конфиг `VIDEO_SLOTS` в начале `script.js` (`ready: false/true`), а не запрос к файлу, поэтому отсутствующее видео не даёт 404 в консоли.
2. **Контакты.** На текущем сайте только email `kulikartur130908@gmail.com` — он единственный контакт (ссылка `mailto:` и кнопка копирования). Телефона, Telegram и Instagram там нет: кнопок `tel:`/`t.me` не делал, вместо них пометки [уточнити]. Кнопка «Як дістатися»/карта не нужна — работа удалённая, адреса нет.
3. **Форма.** Главное действие — написать письмо, поэтому формы нет и секретов в коде нет. Если понадобится форма, подключите Formspree (`action="https://formspree.io/f/ВАШ_ID"`) — ключи в код не кладите.
4. **Услуги.** Отдельного списка услуг на сайте не было. Список собран только из слов сайта: talking-head reels, podcast clips, motion graphics, kinetic captions, interface animation, colour & mood, pacing, b-roll. Колонка «Seen in» ссылается на рилсы, в описаниях которых эта работа названа (например, Interface animation → «I asked AI»).
5. **Как я работаю.** Блок «How a cut happens» собран из фраз сайта («Send a link to your footage or a reel you like, and tell me what it’s for», «a look designed around each story») и «price on request»; срок — [уточнити].
6. **Аудитория и формат работы** («YouTube creators & podcasts · US & Europe», «Remote») взяты из анкеты.
7. **Новые подписи интерфейса** — «Book an edit», «The cut list.», «Watch the selects», «Skip intro», подписи сцен — это навигация, а не факты. Клиентов, отзывов, цифр и опыта на сайте нет.
8. **Тайм-код.** Суммарная длина 9 рилсов — 403,98 с (проверено ffprobe: 403,983 с). При 24 fps это 9 696 кадров, то есть `00:06:44:00`. Шапка EDL («TITLE», «FCM: Non-drop frame») — оформление в формате монтажного листа, а не данные.
9. **Ветка.** Бриф просил `redesign/immersive`, но среда задала своё имя ветки — работа лежит в `claude/hopeful-newton-4j3s9p`. В `main` ничего не пушилось.
10. **WebGL2.** three.js r170 работает только с WebGL2; браузеры без него получают статичную версию.
11. **Шрифты.** Сайт английский, кириллица не нужна. Единственное исключение — пометки [уточнити]: они набираются системным шрифтом (у Instrument Sans нет кириллицы). Это временные пометки, при замене данных они исчезнут.
12. **Open Graph** использует существующий постер «Identity — Noir Gold» (720×1280); горизонтальная картинка 1200×630 описана в PHOTOS.md.
13. **schema.org** — `Person` с email и сферой работы, без адреса и телефона (их нет).

## Проверка (что сделано и чем)

Проверял в этом облачном окружении Playwright + Chromium (рендер WebGL — программный SwiftShader, GPU нет).

- **Скриншоты** каждой сцены на 375×667, 768×1024 и 1440×900 в иммерсивном режиме; статичная версия на 1440 (`prefers-reduced-motion`), без WebGL, с недоступным CDN и без JS (375). Найденное кривое исправлено (sticky-панель первой сцены, сетка карточек, bloom на светлом видео, раскладка сцены 04, линия-плейхед, отсечённая как задняя грань, обрезанные подписи таймлайна).
- **Горизонтальная прокрутка:** 0 px во всех режимах и ширинах.
- **Консоль:** в иммерсивном и статичном режимах нет ошибок и предупреждений. При недоступном CDN браузер пишет сетевую ошибку загрузки модуля (`net::ERR_FAILED`) — это сам сбой сети, сайт при этом показывает статичную версию.
- **Ссылки:** все локальные `href`/`src`/`data-src` и якоря существуют; единственный контакт — `mailto:`.
- **Интерактив:** клик по 3D-карточке открывает плеер с нужным рилсом, клавиши ↑/↓/Esc работают, кнопка «Watch with sound», клик по клипу таймлайна, копирование почты, «Skip intro» (фокус переходит на h1), появление текста не прячет кнопки от клавиатуры.
- **Тайм-код:** ширина `00:00:00:00`, `11:11:11:11`, `00:06:44:00`, `08:38:27:19` в браузере одинаковая (91,19 px) — `tabular-nums` не дёргается.
- **Контраст** всех пар цветов посчитан скриптом (DESIGN.md), всё проходит WCAG AA.
- **Буквы в шрифтах:** все символы текста есть в League Gothic и Instrument Sans (кроме кириллицы в [уточнити], см. п. 11; знак «±» заменён).
- **Вес первой загрузки** (иммерсивный режим, сжатие как на CDN): HTML 7,8 КБ + CSS 9,5 КБ + JS 26,5 КБ + three.js 171 КБ + GSAP 107 КБ + шрифты ≈ 66 КБ + два первых постера 240 КБ ≈ **0,63 МБ** (без сжатия — 1,5 МБ по замеру Playwright). Лимит 3 МБ выполнен.
- **encode.sh** прогнан на синтетическом 1080p-клипе и на реальном ролике: файлы ≤ 4 МБ, у `scrub` ключевой каждый кадр; тестовые видео подставлены во все три слота — работают.

**Что не проверено честно:** FPS. В облаке нет GPU, WebGL рисуется программно (SwiftShader): 4–5 кадров/с на 1440 с bloom и около 40 кадров/с на 375 — это скорость эмулятора, а не ноутбука или телефона. Цели 60/30 кадров/с заложены (меньше частиц и DPR на телефоне, адаптивное снижение качества), но замерить их можно только на реальном устройстве: откройте сайт в Chrome → DevTools → Rendering → Frame rendering stats.
